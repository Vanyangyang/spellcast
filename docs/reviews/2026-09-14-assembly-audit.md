# 原子形式组装审查

## 定义

用户确认：多个可编辑、可搭配的原子形式共同构成一个完整 idea。组合不仅是同屏显示或把几张卡片框选成组。

## 当前能力与缺口

| 维度 | 已有实现 | 仍缺的能力 |
| --- | --- | --- |
| 原子粒度 | 顶层原生文字、图片、形状；旧节点、结构化回复和交互作品可作为 CanvasObject 呈现 | 对比、图、步骤、artifact 主要仍在 reply.blocks 中，不是所有组件都有一致的独立对象编辑、抽取和复用入口 |
| Idea 身份 | CanvasComposition 有稳定 ID、revision、title、members、source_id，支持嵌套 | 更完整的 idea 语义、背景与来源呈现；界面组合操作仍默认叫“组合”，缺少连贯的命名、阅读和整体继续工作体验 |
| 组装操作 | 多选、组合、解组、整体移动、层级和布局撤销/重做 | 组件插入面板、局部抽取、整组复制/复用、可重复使用的组合模板，及组合内部的布局约束 |
| 数据连接 | 声明输入输出、兼容类型校验、无环传播、旧输出失效、断开回退 | 目前类型限 number/string/boolean/null；表格、数组、图像、几何和媒体片段缺少共同的类型与适配协议 |
| 生命周期 | 对象与组持久化、独立版本、草稿和修改保护；artifact 可单独导出 | 完整 idea 连同组件、依赖、参数、来源一起复制、导出、恢复的验收；复杂混合组合的长期修改矩阵 |
| Agent 闭环 | 准确任务绑定、反馈 sequence、响应对象关联、版本冲突提案 | 当前 Codex 交付仅 thread/queue/add；空闲原任务继续执行，以及用户就地操作后结果回原内容的完整体验未验收 |

## 下一条完整验收样本

以“说明文字＋对比＋关系图＋可调参数作品”组装一个 idea；局部编辑，整体移动，关闭重开，修改上游参数，再在其中一个组件上提出修改，交给同一 Codex 任务，返回后保留未授权修改的组件、用户草稿、来源和布局。分别加入过期版本、网络失败和重复提交。只有这一链条通过，才将该组合范围标为可用。
