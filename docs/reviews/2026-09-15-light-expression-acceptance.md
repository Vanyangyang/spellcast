# 轻量文字、组合编排与任务继续验收

## 已实现

- 普通组件的隐藏标题栏从显示和辅助功能树中移除。画布工具栏保留可见的“进入内容”入口；卡片标题栏按钮的鼠标事件不会落到画布选择层。
- 局部提问成功创建请求后收起表单，并将焦点返回“提问”。处理进度继续由底部真实交付回执呈现，移除另一处静态“已保存”状态。
- 原生文字对象和文字回复块支持轻量 Markdown 展示：强调、斜体、引用、链接、列表、行内与块代码。编辑仍保存原始文本；无标题短句使用正文摘要作为导航与讨论标签，不强加正文标题。
- Marked 仅分词，所有输出使用 DOM 节点与 textContent。HTML 保持惰性文本，Markdown 图片不加载；链接只允许 HTTP(S)/mailto。代码与引用使用画布主题色。
- 组合增加 `arrangement`：free、side_by_side、figure_caption、sequence。保存观看方式不移动内容；“保存并编排”才在同一事务中执行 arrange。三种布局分别为横向顶对齐、主体及下方说明、纵向连续展开；保持尺寸、内容、成员与关系线。
- arrange 必须声明组合版本及全部直接成员的呈现版本。陈旧、缺失、多余版本、隐藏成员、嵌套组合会保留为整批提案；Agent 不能覆盖用户修改过的位置。用户审阅应用提案时重新检查全部呈现版本，包括 compose→arrange 的后置组合版本。
- 组合面板有观看方式示意，内容区滚动，保存操作保留在底部。首版按组合的直接对象成员编排，不展平嵌套组合，不增加模型服务。
