# 图片引用与子对象指向：第一轮实现及验收

本轮完成原子表达审查的第一段流程：同一 Idea 的图片可以进入比较项和分镜步骤；用户选中项或框选其画面后，最终发送保留准确身份和画面。未把审查中的六项建议全部标记完成。

## 实际行为

- 比较选项、分镜步骤支持 `image` 固定快照，保存图片对象 ID、内容版本、标题、说明和资源。编辑界面仅列出同一组合内可引用的图片；不同已知工作区或任务来源不能新建引用。
- 首版引用本地 artifact 图片资源或 PNG/JPEG/WebP data URL。网络图片需要先保存为本地资源；此字段不启动作品实例，也不表示作品状态预览或任意递归嵌套。
- 原图变化不会替换旧画面。显示原图已更新、原图离开组合、原图不可用或资源读取失败；更新引用是明确编辑。移除引用不改变图片所有权或组合成员。
- `CanvasAnchor.target` 携带稳定子项类型和 ID；比较和分镜可选中具体项，原有图节点选择也携带 ID。选中反馈及底部讨论对象使用所选项名称。Graph edge 的协议目标可以校验，但本轮没有新增关系线选择界面。
- 比较与分镜图片支持归一化局部框选。发送携带固定画面快照；不使用标题或序号作为唯一定位依据。步骤局部提问不再把标题前缀拼进用户请求。
- 编辑、选择、重排和刷新引用留在本地；最终显式发送才形成反馈。默认接收原任务以及更换任务确认沿用现有流程。
- 新引用在整个 Canvas transaction 模拟完成后校验，允许一次创建图片、组件和组合；失效更新保留为原子提案。旧快照可随无关编辑保留，不要求原图始终保持旧版本。
