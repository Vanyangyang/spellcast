# 持久注释、紧凑作品与状态引用

三项能力已实现、通过代码与隔离浏览器验收，并更新到本地桌面运行版。详细证据见 [验收记录](2026-09-15-durable-expression-acceptance.md)。

## 已确定的边界

- CanvasLayout.annotations 独立于反馈历史保存；稳定 ID、注释版本、准确 anchor、后端捕获的原内容 snapshot、正文、原来源与软移除状态。保存或修改注释不产生反馈，最终发送携带所选注释版本与当时的 annotation_context。
- 新 annotate / remove_annotation 操作与 annotation read kind 走原子事务、版本和用户保护。原目标改变后可以继续编辑旧注释正文，不偷偷重新关联。
- 比较项和分镜可带 artifact 固定引用，保存 object/content/block/bundle/state 身份和完整参数，可带预览图片。只接受同一 Idea、来源与工作区的准确新引用；保留已有旧引用。
- 作品可通过 onSnapshot 提供当前画面；异步捕获时参数变化必须拒绝关联。没有回调时仍可引用已保存参数，不能伪造截图。
- 引用默认不启动第二个作品。用户明确重现时才在只读沙箱用保存 bundle/state 初始化，禁止回写原作品或触发模型。
- 紧凑/完整显示偏好按稳定对象/块保存在前端。仅用户明确切换单作品卡片的显示时调整该呈现高度；自动测量不改用户布局。
- 保存、标注、参数交互与重现保持本地；最后点击发送才交给对应 Codex 任务。
