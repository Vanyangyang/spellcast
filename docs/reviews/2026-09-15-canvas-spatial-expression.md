## 改动

- 原子根 DOM 以 X6 节点当前宽高设置显式 CSS 像素，初次挂载和每次 size 变化同步；不重建编辑器或作品 iframe。处理 WebView2 中选框已变、HTML 容器仍保留旧绘制尺寸的问题。
- 原生文字、图片、形状进入操作态时先保留内容；明确点击「编辑」才展示属性与正文编辑。保存成功返回内容，退出编辑不会丢弃草稿，未保存草稿仍阻止最终发送。
- 联动长句使用 17px 正文；数值才使用大号排印。短的无标题独立念头获得更明显的文字分量。
- 同一组合内完全相同的来源在阅读态避免逐块重复，选中后仍可见；不同来源继续区分。图片不再出现黑色留边；健康引用状态与无选区清除按钮减少占位；比较在阅读态减轻外框。
- 日历示例收为四个可见部分：一句念头、两张画面的比较、间隔交互、联动短说明。重复原图、教学说明、分镜的展示被收起，底层对象、引用和注释保留。用户已调整的文字块位置与尺寸未纳入重新布局。
- Canvas 参考指引强调表达意图、焦点和支持关系，避免用组件数量代替表达质量。
