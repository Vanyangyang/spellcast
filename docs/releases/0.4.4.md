# Spellcast 0.4.4 — Codex-only setup, Grok Build later

Windows is the only tested platform.

## Changes

- **Settings install is Codex-only.** The Grok Build button stays visible but disabled, with copy that it will be added in a future version. The desktop complete-setup commands refuse a Grok install so they cannot write `~/.grok`.
- Hook/Skill merge helpers stay in the library for that later release: they only touch Spellcast’s own MCP table, `skills/spellcast`, and a Stop group in `hooks/spellcast.json`, and they refuse invalid user JSON.

## Verification

- `cargo test --manifest-path src-tauri/Cargo.toml --lib unsupported_clients`
- `npm run check:i18n`, `npm run check:complete-setup-ui`, `npm run check:complete-setup-preview`
- Local Windows NSIS install of this build
