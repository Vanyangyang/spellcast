# Spellcast 0.4.8 — readable spatial cards and dark menus

The Windows installer was built locally. The release workflow also builds macOS and Linux packages.

## Fixes

- **Idea layout contrast:** Spatial cards now use an unlit, opaque card surface. Scene lighting and colored emissive light no longer wash out their title or body text. The card texture refreshes when its content or kind changes.
- **Native select menus:** Dark and light themes explicitly style option text, background, and the selected item so the Windows drop-down list remains readable.
- **Clearer action:** The idea button now says that it asks the Agent to develop the idea, with a tooltip explaining that it creates linked Canvas content and does not edit project files.

## Verification

- `npm run build` and `npm run check:i18n`.
- `node scripts/check-spatial-contrast.mjs` in an isolated Chromium browser: screenshots of enlarged spatial cards and an open dark select menu, plus computed dark/light option colors.
- Existing Canvas workspace and recipient browser regressions.

The browser fixture checks presentation and controls; it does not claim a live Codex task performed a new Canvas send-back.
