# Spellcast 0.4.3 — Grok Build completion notices, English/Chinese UI

Preview build for the Product Hunt launch (GPT-6 Astra Challenge). Windows is the only tested platform.

## Changes

- **Grok Build completion notices.** The Grok Build setup now also installs `~/.grok/hooks/spellcast.json`, a lifecycle `Stop` hook that runs the Spellcast helper (`--grok-notify`). A finished turn (`reason = end_turn`) becomes a completion card; session shutdown does not. The older `[[ui.notifications.hooks]]` entry in `config.toml` did not fire in the TUI and is removed on install/uninstall. Cards carry a `client` (`codex` / `grok`); Grok cards dismiss on double-click instead of deep-linking into Codex Desktop.
- **UI languages: English and Simplified Chinese.** Japanese is parked (kept key-complete for a later return) and migrates to English when detected. The completion card, the spoken phrase (`A Codex task is ready.` / `Codex 有任务完成了。`), the card window title, and the setup page follow the same setting; the choice is persisted and synced to the Rust side (`set_ui_locale`) and across windows.
- **Completion card window.** The card window is created once at startup and then only shown, moved, and hidden. It is re-anchored to the display holding the foreground window each time the list changes. This removes a hang seen when a transparent always-on-top WebView2 window was built in the middle of a completion.
- `scripts/check-i18n.mjs`: catalog parity, parked-locale key completeness, `ja → en` migration, and a Vite preview check of the language switch.

## Verification

- `cargo test --manifest-path src-tauri/Cargo.toml --lib` (88 passed, 2 ignored) and `npm run build` on Windows.
- Real end-to-end run with Grok Build on `G:\Demos\Platformer`: bubble → star → double-click onto the Canvas; `spellcast_canvas_batch` content on the board; `Stop` hook → completion card with English speech. Recording: `docs/media/spellcast-grok-demo.mp4`.
- Known: after `spellcast_canvas_batch`, the board window did not repaint the new objects until refreshed; the API returned them. Codex-side flows were not re-recorded (quota).
