# Spellcast 0.4.11 — stable bubbles, locale-bound asides, and Canvas continuity

This release makes the desktop preview more predictable across bubble interaction, Agent language selection, Canvas reading, and Windows host boundaries.

## Changes

- Unfavoriting a bubble after repeated dragging now resumes at the original rise speed instead of stretching the remaining distance over a fresh full lifetime.
- Completion notices no longer activate themselves when shown on Windows. Transparent space around the cards passes clicks through to the desktop while the visible controls remain interactive.
- Observer briefs carry the App-selected locale. Chinese Spellcast sessions now require Simplified Chinese asides even when the task snapshot or source material is English.
- Canvas adds typography controls and restores the active reader, selection, scroll position, and camera state across remounts.
- Windows desktop state now uses `%USERPROFILE%\.spellcast\spellcast.sqlite3`, outside host-specific AppData virtualization. The first migration preserves the complete SQLite state and refuses ambiguous or unsafe migrations instead of guessing.
- README and storage documentation describe the current release and migration boundary.

## Verification

- Bubble-flight, completion-pointer routing, Canvas workspace, and Canvas typography regressions pass locally.
- Frontend build, workspace Rust tests, and Tauri library tests pass locally.
- The release workflow repeats the builds and Rust tests before publishing Windows, macOS, and Linux packages.
