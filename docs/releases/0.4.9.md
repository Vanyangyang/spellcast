# Spellcast 0.4.9 — readable Canvas atoms and multi-selection

The Windows installer was built locally. The release workflow also builds macOS and Linux packages.

## Improvements

- **Long Canvas replies:** Open a near-full-window reader with a block outline, read individual blocks, and return to the same scroll position. Editing uses the available window space and keeps draft and save-error state visible.
- **Multi-selection:** Select cards with Ctrl, Shift, or a drag box; select reply blocks; view selected content side by side, copy it with source labels, or bring it into the Canvas composer for discussion.
- **Layout and grouping:** Use selection actions to align, arrange, or group separate cards. Left alignment now places cards below one another when their heights would overlap. Grouping keeps members editable and can be undone without deleting their content.

## Verification

- `npm run build` and `npm run check:i18n`.
- `scripts/check-canvas-atom-workspace.mjs` in an isolated Chromium browser: selection, alignment and undo, block comparison, scroll restoration, editing states, and Canvas placement.
- `cargo test --workspace --locked` and a local Windows NSIS package build.

The browser fixture checks Canvas controls and presentation; it does not claim a live Codex task completed a new send-back.
