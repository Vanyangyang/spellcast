# Spellcast 0.4.2 — macOS complete-setup tests under `/var`

Same product as [0.4.0](0.4.0.md). `v0.4.1` still failed GitHub macOS `--lib` tests.

## Changes

- Do not treat macOS system prefixes (`/var` → `/private/var`, `/tmp` → `/private/tmp`) as hostile reparse points. Complete-setup walks ancestors to block user-controlled junctions; stopping at those prefixes lets a plugin tree in `TempDir` (`/var/folders/...`) install. User profiles under `/Users` were already fine.
- Keep the Windows-only nested libtest lock coverage from 0.4.1.

## Verification

- Windows: `cargo test --manifest-path src-tauri/Cargo.toml --lib complete_setup -- --test-threads=1`.
- **Windows only tested** for interactive desktop use. macOS `.dmg` files remain unsigned CI packaging.
