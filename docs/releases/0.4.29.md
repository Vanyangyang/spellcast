# Spellcast 0.4.29 — autonomous Sigil execution

Date: 2026-10-07. Local Windows build and installer verified; not published to a remote release.

Sigils now default to autonomous execution. After an explicit user instruction, a native agent
can freeze, start and claim its plan with `execute`. The window offers one combined start and
handover confirmation, retaining freeze-only as a secondary action.

- Recorded amendments automatically authorize their verification commands in autonomous runs.
  Real command failures still prevent dependent work and return the step for repair.
- Ordinary manual checks remain explicitly deferred and do not prevent dependencies or completion.
  They never count as a pass. `blocking:true` retains essential human decisions.
- Manual reviews can be recorded and corrected directly after autonomous execution finishes.
  A failed late review remains visible without suggesting an executable step in a completed run.
- Durable preparation records recover the same registered worktree after an interrupted start,
  checking repository, branch and baseline identity and preserving existing changes.
- Runs without an automation field retain their supervised behavior. Client grants remain
  draft-only; window execution continues to require the window credential and trusted origin.
- Agent instructions favor short plans and ordinary direct work for small edits. The new Sigil
  reference is included in native and packaged skill installation and integrity checks.
