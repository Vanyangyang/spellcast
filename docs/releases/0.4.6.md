# Spellcast 0.4.6 — selectable themes and clearer task connection

Windows is the locally tested platform. The release workflow also builds macOS and Linux packages.

## Changes

- **Appearance:** Dark is the default across the desktop, Settings, Canvas, and idea layouts. Light and system-following themes are available in Settings; the choice persists. Canvas grid colors change with the theme.
- **Integration checks:** The desktop home now shows MCP, Skill, and Hooks separately. Partial installs report the actual missing pieces, and Hook trust remains visible even if another piece is missing. Recent activity still shows live calls separately from file checks.
- **Canvas send-back:** A missing binding to an original Codex task is shown as an unlinked task, distinct from a host without send-back support. For a source named `codex:<task UUID>`, the user can explicitly reconnect that exact task. Spellcast verifies the task and working directory before enabling Send; it never sends automatically.

## Verification

- `npm run build`, `npm run check:i18n`, `npm run check:complete-setup-ui`, and `npm run check:complete-setup-preview`.
- `node scripts/check-canvas-recipient.mjs` with a missing-binding fixture and an explicit reconnect click.
- `cargo test --manifest-path src-tauri/Cargo.toml --lib complete_setup::tests::codex_direct_` (9 tests).
- `cargo test --workspace --quiet` and `cargo test --manifest-path src-tauri/Cargo.toml --lib --quiet` (105 passed, 2 ignored in the desktop library).
- Local visual preview of dark and light desktop, Settings, Canvas, and idea layouts. The preview's install status is a fixture; it is not a live-host setup verdict.

The missing-binding case was reproduced against the local desktop and confirmed as `unlinked`; the new reconnect action was verified in an isolated browser fixture. A live reconnect of the affected task has not been claimed.
