# Spellcast 0.4.10 — complete Canvas usability release

This release carries the Canvas reading, editing, and multi-selection improvements described in [0.4.9](0.4.9.md). It replaces the incomplete 0.4.9 desktop release: its Windows CI job stopped before packaging because an asynchronous Hook diagnostic test read its log too early.

## Release fix

- The Hook diagnostic test now waits for each background log write before checking the records. Hook runtime behavior is unchanged.

## Verification

- Canvas browser regression, frontend build, and i18n check passed; the Canvas code is unchanged from 0.4.9.
- `cargo test --workspace --locked` and `cargo test --manifest-path src-tauri/Cargo.toml --lib --locked` passed locally.
- The Windows 0.4.10 NSIS installer was built locally. The release workflow repeats the tests and builds the other desktop packages.
