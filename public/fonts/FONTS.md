# 字体来源

本目录字体随 Spellcast 前端资源分发，不安装到系统。

| 文件 | 字体 | 许可 |
| --- | --- | --- |
| `noto-sans-sc-*.woff2` | [Noto Sans SC](https://github.com/notofonts/noto-cjk) | SIL Open Font License 1.1 |
| `noto-serif-sc-500.woff2` | [Noto Serif SC](https://github.com/notofonts/noto-cjk) | SIL Open Font License 1.1 |
| `cormorant-500-italic.woff2` | [Cormorant Garamond](https://github.com/CatharsisFonts/Cormorant) | SIL Open Font License 1.1 |

通过 Fontsource / jsDelivr 下载的 woff2 子集。界面中文用 Noto Sans SC 500；字标用 Cormorant Garamond Italic；作品大标题用 Noto Serif SC。若本地文件未加载，界面回退到 Microsoft YaHei UI，不回退到宋体。

完整许可证与版权声明一并保留：`LICENSE-notosanssc.txt`、`LICENSE-notoserifsc.txt`、`LICENSE-cormorantgaramond.txt`，对应 Google Fonts 仓库各字体目录中的 `OFL.txt`。
