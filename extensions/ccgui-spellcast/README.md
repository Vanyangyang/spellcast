# Spellcast 原会话回发插件

需要提供公共 `ctx.chat` SDK（包括 `chat.identity()`）的 CC GUI 桌面版（此兼容开发版本最低 1.1.1）、本机 Spellcast，以及其原生连接密钥。`identity()` 即使没有选中聊天，也必须返回真实的 `clientInstanceId`、`windowId`。API 缺失或身份无效时，插件显示原因并停止连接，不回退到共享账本。普通未扩展版本、远程 Web 页面不支持此插件。

## 安装与配对

1. 在 CC GUI 侧边栏「插件」→「从本地目录安装」，选择本目录（包含 `manifest.json`）。
2. 打开准确的 Claude 原聊天，在插件的「Spellcast 回发」设置中填入本机 Spellcast 提供的连接密钥，点击「连接」。密钥仅保存于本插件的隔离存储，不显示于状态或日志。
3. 在 Canvas 发送请求。插件冻结原生 UUID、GUI UUID、工作区、桌面实例、窗口以及租约，不因切换标签或 Canvas 焦点改投。执行与权限问答均沿用原聊天；权限卡片必须在原 GUI 操作。
4. 设置中的每个请求提供「打开原聊天」按钮，按该请求保存的引擎、GUI 会话 ID、工作区调用公共 `sessions.selectSession`。完整结果保留在该聊天；画布回复按 Unicode 字符截到 16,000 字符，并标记截断。
5. Spellcast 桌面的完成提示：双击 Claude 完成卡片时，Spellcast 通过同一个请求轮询下发“聚焦”请求，插件调用同一个公共 `sessions.selectSession` 打开对应聊天，并用一次明确注意力心跳应答；每个请求编号只处理一次，切换失败不影响轮询和 Canvas 请求。你在聊天里或聚焦 CC GUI 窗口并停在该聊天时，插件已有的注意力上报也会让 Spellcast 移除那条完成卡片。把窗口提到前台由 Spellcast 完成，SDK 没有这个能力。

## 更新、暂停与卸载

更新后再次「从本地目录安装」同一目录，同 ID 覆盖并热重载，无需新建目录（0.1.2 起支持完成提示的聚焦请求，需要重新安装一次）。「暂停」停止本插件接收与状态同步。卸载在 CC GUI 插件页操作；宿主保留插件数据 30 天。卸载或暂停不停止已经开始的原聊天任务。

## 恢复规则与限制

同一桌面文档中的插件重载保留回执序号、内容指纹、冻结目标与未确认传输；HTTP 错误只重试回执，不重放模型提交。连接过期后，仍准确打开的会话可获得新租约供新请求使用，旧请求保留旧租约并保持未知，不迁移。关闭聊天后仅按原描述查找；手动重新打开可恢复可达性，但已经过期的旧请求不重发。

回执账本先通过公共 `chat.identity()` 获取真实桌面身份，再以完整的 `[clientInstanceId, windowId]` 二元组构造隔离存储键。每个窗口独立保存自己的租约、请求、回执序号和待发送内容；一个窗口的完成不会覆盖另一个窗口的待确认回执。后台忙碌时，SDK 已持久化接受的 `queued` 回执仍保持排队状态，接收时间由 Spellcast 记录；只有宿主报告开始执行才同步执行状态。

桌面应用重启会产生新的实例身份。新窗口不读取旧窗口的账本，旧请求仍绑定原租约，失联或过期由 Spellcast 显示为未知，不能自动重放。旧版共享键 `delivery-ledger-v1` 的数据保持原样，不读取、迁移或复制其中的活租约和请求；升级后旧请求的继续确认受到这一兼容限制。存储失败会阻止未持久化的回执传输；提交结果不明确时也不会自动再提交。SDK 已有回执必须确认完全相同的目标。冲突的请求 ID、事件序号、目标或正文会被拒绝。

启动扫描和后台心跳只报告存活，不抢占活动会话。仅「连接」及新的宿主 `session://activated` 事件报告注意力；切到 Canvas 不清空最后真实宿主目标。

冷启动和明确激活聊天时，公共 SDK 的 `current()` / `inspect()` 可能仍在等待历史加载。启动发现会每 200 毫秒重试，最多 10 秒，首次得到完整描述后冻结原生/GUI UUID、工作区和实例/窗口身份，始终以 `active:false` 登记。明确激活则保留该事件的引擎、原生 UUID 和可选完整目标，只接受同一个明确会话；新的有效聊天激活会取消旧意图或启动发现，Canvas/空选择不会取消，卸载会清理重试计时器。超过 10 秒仍未加载时停止本次重试并显示提示，需要重新激活该聊天或点击连接。后台心跳不制造注意力。

首次登记遇到 5xx 或连接失败时，只在同一 10 秒预算内重试冻结的目标，退避间隔依次为 250、500、1,000、2,000 毫秒（后续最多 2,000 毫秒）。401/403 会显示配对错误并停止自动登记；同窗口插件重载也保留此停止状态，不改动保存的密钥或启用状态，需要用户重新填写密钥并明确点击「连接」。重试登记不重做模型提交或改变旧请求的冻结租约。

设置显示无凭据诊断；同一内容保存在插件自身的窗口隔离键 `diagnosis-v1:` 加上 JSON 编码的 `[clientInstanceId, windowId]`。记录仅含 `enabled`、`hasCredential`、`currentReady`、`stage`、`httpStatus`，可通过已有 SDK/原生存储读取本插件的诊断，不新增网络接口，不包含密钥、token、正文或原始传输错误。

本插件只用公共 SDK，单文件 ESM 无导入、DOM、私有 store、文件系统或 Tauri 旁路。网络授权仅 `127.0.0.1:47194`。验证：在仓库根目录运行 `node scripts/check-ccgui-spellcast-plugin.mjs`。脚本包含假 SDK/HTTP 生命周期测试，以及从兼容宿主开发副本内存转译实际 `chat-bridge.ts`、注入宿主/存储/引擎事件的组合测试（需要该副本已有的 TypeScript 依赖，不安装额外包）。覆盖 busy 接收落盘后丢失确认、匹配 spawn ACK 前收到 done、真正开始前出现 typed busy 错误；测试不调用真实模型或应用。此验证不替代真实桌面 GUI 验收。
